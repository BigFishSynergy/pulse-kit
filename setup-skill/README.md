# The Pulse setup skill

It lives at `.claude/skills/pulse-setup/SKILL.md`, so Claude Code (including the Code tab in the Claude desktop app) picks it up on its own in any copy of the kit. Open the copy in Claude Code and say "Help me set up my Pulse."

Using Claude in a chat instead? Download `.claude/skills/pulse-setup/SKILL.md` from your copy on github.com and add it in Claude (Customize, Skills).
